## Project Title
[Juana_Blog]

## Description
This website is a clean, interactive personal portfolio designed to showcase my academic profile, technical skills, semester-by-semester CGPA achievements, and creative software development projects. The site is engineered with a modern visual hierarchy, featuring a premium dark mode aesthetic contrasted by sleek matte-light navigational elements, and is fully optimized for a responsive user experience across all device screens.

## Features
Here are the key features implemented in this portfolio project:
- Interactive Navigation Overlay Menu: A clean, screen-covering navigation overlay triggered smoothly by a custom-styled hamburger menu button.
- Academic Achievements Grid: An aligned, structured layout that cleanly maps out cumulative GPA metrics semester by semester with hover-triggered elevation.
- Technical Skills & Software Showcases: A dual-column arrangement displaying specialized development fields alongside a modern logo grid highlighting industry software competencies.
- Premium Cinematic Aesthetics: A dark-themed layout using sophisticated backdrops, custom glow borders, and strict contrast coordination matching the top navigation and bottom footer elements.
- Smooth Scrolling & On-Scroll Animations: A fluid user journey powered by a dedicated scroll-animation framework, orchestrating clean slide-up transitions as elements enter the viewport.
- Responsive Web Design (RWD): Fluid adjustments designed across CSS media breakpoints to guarantee layout integrity from smaller smartphone screens up to desktop monitors.

## Technologies Used
This project was developed utilizing the following core frontend technologies and libraries:
- HTML5 – Used to build the semantic structure, component blocks, and informational layout of the web pages.
- CSS3 – Used for modern styling, layout positioning (Flexbox and Grid systems), responsive styling, custom color variables, and transition management.
- JavaScript (ES6) – Used to manage UI logic, state control for the overlay navigation panel, and handle dynamic interactive elements.
- AOS (Animate On Scroll) Library – A performance-optimized third-party animation library used to synchronize transition events with the user's scroll behavior.
- Google Fonts (Inter) – A clean, modern sans-serif typeface integrated to establish high readability and a professional visual tone.
