# Juana Personal Blog Portfolio

Projek ini adalah sebuah laman web blog peribadi yang dibangunkan sebagai tugasan individu untuk subjek **CSD 34203 Special Topics in Software Development** di UniSZA.

## Ciri-Ciri Utama (Features)
- **Halaman Utama (Home):** Pengenalan ringkas pemilik portfolio.
- **Halaman Mengenai Saya (About):** Latar belakang dan kemahiran.
- **Halaman Blog:** Mempunyai 2-3 contoh artikel pendek.
- **Halaman Hubungi (Contact):** Borang hubungi dan maklumat media sosial profesional.
- **Responsif:** Paparan web yang kemas di skrin komputer mahupun telefon bimbit.

## Teknologi yang Digunakan (Technologies Used)
- HTML5 (Struktur halaman web)
- CSS3 (Gaya reka bentuk dan responsif)

## Cara Menjalankan Projek
1. Muat turun (Clone) repositori ini.
2. Dwi-klik (Double-click) pada fail `index.html` untuk membukanya di dalam mana-mana pelayar web (Browser).
